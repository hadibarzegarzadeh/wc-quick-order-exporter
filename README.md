# WooCommerce Quick Order Exporter

A highly practical WooCommerce extension to export your shop's orders to a CSV file. Includes filtering by date ranges and order statuses.

## Features

- Custom admin dashboard under the WooCommerce menu.
- Date range filtering (Start Date to End Date).
- Order status filtering.
- Lightweight and fast without unnecessary overhead.
- Outputs clean CSV files formatted for Excel or Google Sheets.

## Installation

1. Upload the `wc-quick-order-exporter` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Ensure WooCommerce is active.
4. Navigate to **WooCommerce > Order Exporter** to begin exporting.

## Usage

Select a start date, end date, and desired order status on the settings page. Click "Export to CSV" to instantly download a comprehensive CSV document containing details of your exported orders.
